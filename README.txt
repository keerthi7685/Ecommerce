ShopEase demo store

HOW TO RUN
1. Extract the ZIP file.
2. Open index.html in a modern web browser.
3. Internet access is needed to load the product photos from Unsplash.

WHAT'S INCLUDED
- Responsive storefront
- Product search and category filters
- Shopping cart with quantity controls
- Demo checkout form

IMPORTANT
This is a front-end demo. Checkout does not process payments or save orders.
To launch a real store, connect a backend, database, and payment provider.
